# Marathon Press - Shipping Pickup Verification Webpage

Color-coded shipping confirmation terminal webpage (`mp-label-confirmation`).

## Carrier Color Coding
Each carrier lights up with its own distinct industry color:
- **USPS**: Postal Blue (`#3b82f6`)
- **FedEx Ground**: Emerald Green (`#10b981`)
- **FedEx Express**: Signature Electric Orange (`#ff6600`)
- **UPS**: Warm Amber Gold (`#f59e0b`)
- **DHL**: Canary Yellow (`#eab308`)
- **UPSMI**: Violet / Purple (`#a855f7`)
- **Internal Jobs**: Marathon Red (`#d3202a`)
- **Not Recognized**: Warning Crimson (`#ef4444`)
