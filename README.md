# Marathon Press - Shipping Pickup Station

Internal shipping and package sorting station for Marathon Press (marathonpress.com).

## Destination Display Rules
- **USPS**: Displays clean "USPS" (no mail cage text).
- **UPS**: Ground and Air consolidated into single "UPS" pickup spot.
- **FedEx Ground**: All ground and SmartPost barcodes show "FedEx Ground".
- **FedEx Express**: Express/2Day air tracking shows "FedEx Express".
- **DHL**: DHL eCommerce and Express packages show "DHL".
- **UPSMI**: Mail Innovations packages show "UPSMI".
